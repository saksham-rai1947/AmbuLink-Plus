# 🚑 AmbuLink+

> **Every Second Counts. Every Life Matters.**

AmbuLink+ is a **real-time emergency response platform** designed to bridge the communication gap between patients, ambulance drivers, and hospitals during medical emergencies.

The platform demonstrates how modern web technologies and cloud services can be integrated to improve emergency response workflows by enabling faster coordination and information sharing.

---

## 🌟 Project Overview

AmbuLink+ provides a centralized platform where emergency requests can be initiated and managed in real time.

The system is designed to simulate the workflow of an emergency response network by connecting multiple stakeholders through Firebase's real-time backend.

This project was developed to showcase practical implementation of frontend development, cloud databases, and real-time data synchronization.

# ⚙️ System Workflow

1. User logs into the platform.
2. An emergency request is created.
3. Firebase instantly synchronizes the request.
4. Ambulance dashboard receives the emergency.
5. Hospital dashboard receives the patient's details.
6. Emergency status is updated in real time.
