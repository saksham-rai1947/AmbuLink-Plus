# 🚑 AmbuLink+

A real-time emergency response system that connects patients, ambulance drivers, and hospitals.

## Features
- Live SOS request system
- Real-time ambulance tracking
- Hospital alert system
- Green Corridor simulation
- Voice alert system for traffic clearance

## Tech Stack
- HTML, CSS, JavaScript
- Firebase Realtime Database
- Web Speech API
- Google Maps Integration

## Vision
To reduce emergency response time using smart coordination between systems.
